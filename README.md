## 🎯 Vision & Core Objectives

1. **Whale & Smart Money Detection**: Real-time identification of institutional accumulation / distribution patterns across all 50+ broker houses.
2. **Floorsheet Microstructure Analysis**: Algorithmic matching of buy/sell depth, order slicing, and true volume-weighted average prices (VWAP).
3. **High-Throughput Distributed Storage**: Powered by CockroachDB for multi-region resilience and ACID guarantees.
4. **Automated Telegram Dossiers**: Instant alerting for abnormal transaction spikes, block trades, and weekly audit scores.

## 🛠️ Tech Stack & Ecosystem

- **Storage**: CockroachDB Cloud (`postgresql`)
- **Backend / Scraper**: Python 3.12 (`psycopg2`, `requests`, `pandas`)
- **Automation**: GitHub Actions Cron Workflows
- **Auditing**: `verify.py` Macro & Micro Contract Reconciliation
